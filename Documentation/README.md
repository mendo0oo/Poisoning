# Documentation

This directory is the research and documentation archive for **Poison Hybrid**.

The public project overview remains at [mend0.net/docs/poisoning.html](https://mend0.net/docs/poisoning.html). This repository section keeps evidence, daily privacy updates, and project-relevant notes behind the ideas described there.

## Project context

Poison Hybrid is a Firefox-first privacy extension focused on:

- tracker and ad blocking
- popup and redirect protection
- fingerprint-surface spoofing
- WebRTC and header privacy controls
- cookie/storage cleanup
- controlled tracker-noise profiles
- Antidote Mode for fragile sites, logins, banking, Cloudflare challenges, and embeds

Poison improves privacy, but it is not anonymity or invisibility. It does not hide an IP address, replace Tor/VPN/account separation, defeat server-side identity systems, or make logged-in first-party tracking disappear.

## Daily privacy research

This archive is updated with meaningful, source-verified privacy developments.

Coverage includes:

- data brokers and identity-resolution systems
- browser tracking, fingerprinting, cookies, telemetry, and ad-tech
- location-data collection and real-time bidding
- surveillance technology and government/commercial access to personal data
- privacy regulation and enforcement
- age assurance and identity verification
- major sensitive-data breaches
- healthcare, financial, education, biometric, location, and government-data exposure
- AI/agent systems where privacy, data leakage, identity, or tracking is materially involved

## Source standard

Prefer regulators, courts, official breach notices, standards bodies, first-party technical disclosures, peer-reviewed research, reputable security research, and high-quality reporting for context.

Avoid minor incidents, duplicate rewrites, marketing posts, unsourced claims, and unverifiable breach claims.
